## B. BACKEND DATA ARCHITECTURE & PERSISTENCE

### 1. MongoDB `annotations` Schema
All reading annotations and marginalia are stored in a dedicated MongoDB collection named `annotations`. Each document strictly adheres to the following specification:

| Field Name | Type | Constraints / Defaults | Description |
| :--- | :--- | :--- | :--- |
| `_id` | ObjectId | Generated by MongoDB | Unique identifier for the annotation record |
| `book_id` | ObjectId | Required, indexed | Foreign key reference to `books._id` |
| `user_id` | UUID String | Required, indexed | Foreign key reference to Django `accounts_customuser.id` |
| `content` | String | 1 to 5,000 characters | The reader's reflection or marginal note |
| `visibility` | String | `"PRIVATE"` (default) \| `"SHARED"` | Privacy level determining public accessibility |
| `page_reference`| String | Optional, max 50 chars | Folio / page number reference (e.g. `"p. 42"`, `"Page 114"`) |
| `chapter_reference` | String | Optional, max 100 chars | Chapter or section reference |
| `passage_excerpt`| String | Optional, max 1,000 chars | Exact excerpt or anchor phrase quoted from the text |
| `created_at` | DateTime (UTC)| Auto-populated on creation | Creation timestamp |
| `updated_at` | DateTime (UTC)| Auto-updated on modification | Last modification timestamp |

### 2. Indexes & Performance Optimization
To guarantee $O(\log N)$ query performance and eliminate full collection scans, the repository initializes compound indexes on collection startup:
1. `(book_id, visibility, created_at DESC)`: Powers public feed lookups on `GET /api/books/<book_id>/annotations/?visibility=SHARED`.
2. `(book_id, user_id, created_at DESC)`: Powers owner lookups on `GET /api/books/<book_id>/annotations/my-annotations/`.
3. `(user_id, created_at DESC)`: Powers future reader cross-book profile annotations.

### 3. Repository Layer (`discovery/annotations_repository.py`)
Encapsulated database operations implemented in the repository:
- `create_annotation(book_id, user_id, content, visibility, ...)`: Validates input, parses ObjectIds, enforces defaults, and inserts document.
- `get_annotation_by_id(annotation_id)`: Fetches single annotation by ObjectId.
- `list_shared_annotations(book_id, limit, offset, sort_by)`: Queries public annotations (`visibility="SHARED"`), with sorting by `created_at DESC` or `page_number ASC`.
- `list_user_annotations(book_id, user_id, visibility, limit, offset, sort_by)`: Queries author's notes with optional visibility filter.
- `count_user_annotations(book_id, user_id)`: Aggregates total, private, and shared counts for the author in a single pass.
- `update_annotation(annotation_id, user_id, ...)`: Updates allowed mutable fields (`content`, `visibility`, `page_reference`, `chapter_reference`, `passage_excerpt`) and touches `updated_at`.
- `delete_annotation(annotation_id, user_id)`: Deletes annotation with ownership confirmation.

## C. PRIVACY MODEL & AUTHORIZATION CONTRACT

The privacy architecture enforces strict confidentiality and ID enumeration prevention:

```
+-----------------------------------------------------------------------------------+
|                           PRIVACY & AUTHORIZATION MATRIX                         |
+-------------------+--------------------+--------------------+---------------------+
| Action / Endpoint | Owner (Author)     | Non-Owner Reader   | Unauthenticated     |
+-------------------+--------------------+--------------------+---------------------+
| GET /my-notes/    | 200 OK (All/Priv)  | 401 Unauthorized   | 401 Unauthorized    |
| GET /shared/      | 200 OK             | 200 OK             | 200 OK              |
| Direct GET (Priv) | 200 OK             | 404 Not Found      | 404 Not Found       |
| Direct GET (Shar) | 200 OK             | 200 OK             | 200 OK              |
| PATCH (Update)    | 200 OK             | 403 Forbidden      | 401 Unauthorized    |
| DELETE (Destroy)  | 204 No Content     | 403 Forbidden      | 401 Unauthorized    |
+-------------------+--------------------+--------------------+---------------------+
```

### Critical Security Properties:
1. **Direct GET 404 Enumeration Protection**: When a non-owner requests a private annotation by its direct URL (`/api/books/<book_id>/annotations/<annotation_id>/`), the view returns `HTTP 404 Not Found` (rather than `403 Forbidden`). This prevents malicious actors from probing or enumerating valid private note IDs.
2. **Author-Only Modifications**: Any attempt by a non-author to edit (`PATCH`) or delete (`DELETE`) an existing annotation is rejected with `HTTP 403 Forbidden` (`{"error": "You do not have permission to modify/delete this annotation."}`).
3. **Safe Author Metadata Serialization**: Shared annotations serialize author information through `AnnotationAuthorSerializer`, exposing only:
   ```json
   {
     "id": "a97ca605-431e-43d3-9c6b-5ff6f85278a9",
     "username": "test_reader_a",
     "display_name": "Aurelius Vance"
   }
   ```
   Email addresses (`reader_a@akashic.vault`), passwords, salt values, and internal permission flags are strictly excluded.

## D. REST API CONTRACT & ROUTE SPECIFICATION

Five REST endpoints were added to `discovery/urls.py` and implemented in `discovery/annotations_views.py`:

### 1. `GET /api/books/<book_id>/annotations/`
- **Purpose**: Retrieve shared public annotations for a specific book.
- **Authentication**: Public (optional session authentication).
- **Query Parameters**:
  - `limit` (int, default 20, max 100)
  - `offset` (int, default 0)
  - `sort` (string, `"recent"` | `"page"`, default `"recent"`)
- **Status Codes**: `200 OK`, `400 Bad Request`, `404 Not Found` (if book does not exist).
- **Response Shape**:
  ```json
  {
    "count": 2,
    "limit": 20,
    "offset": 0,
    "results": [
      {
        "id": "6af8904c84e5b65862a0fd51",
        "book_id": "6af72791ebebc613760355ec",
        "content": "Borges explores the nature of infinity through hexagonal galleries...",
        "visibility": "SHARED",
        "page_reference": "p. 23",
        "chapter_reference": "",
        "passage_excerpt": "The garden of forking paths is an incomplete, but not false, image of the universe.",
        "created_at": "2026-11-14T16:50:00Z",
        "updated_at": "2026-11-14T16:50:00Z",
        "author": {
          "id": "a97ca605-431e-43d3-9c6b-5ff6f85278a9",
          "username": "test_reader_a",
          "display_name": "Aurelius Vance"
        },
        "is_owner": true
      }
    ]
  }
  ```

### 2. `POST /api/books/<book_id>/annotations/`
- **Purpose**: Inscribe a new annotation (Private or Shared) anchored to a book.
- **Authentication**: Required (`IsAuthenticated`).
- **Request Body**:
  ```json
  {
    "content": "My private contemplation...",
    "visibility": "PRIVATE",
    "page_reference": "p. 42",
    "chapter_reference": "Chapter 2",
    "passage_excerpt": "Direct quote from text"
  }
  ```
- **Status Codes**: `201 Created`, `400 Bad Request`, `401 Unauthorized`, `404 Not Found`.

### 3. `GET /api/books/<book_id>/annotations/my-annotations/`
- **Purpose**: Retrieve all annotations created by the requesting user for this book, with author ledger count totals.
- **Authentication**: Required (`IsAuthenticated`).
- **Query Parameters**:
  - `visibility` (optional, `"PRIVATE"` | `"SHARED"`)
  - `sort` (optional, `"recent"` | `"page"`)
- **Status Codes**: `200 OK`, `401 Unauthorized`, `404 Not Found`.
- **Response Shape**:
  ```json
  {
    "counts": {
      "total": 3,
      "private": 2,
      "shared": 1
    },
    "count": 3,
    "limit": 50,
    "offset": 0,
    "results": [ ... ]
  }
  ```

### 4. `PATCH /api/books/<book_id>/annotations/<annotation_id>/`
- **Purpose**: Update an existing annotation's content, visibility, or reference anchors.
- **Authentication**: Required (`IsAuthenticated`), Author-only.
- **Request Body**: Partial update of allowed fields (`content`, `visibility`, `page_reference`, `chapter_reference`, `passage_excerpt`).
- **Status Codes**: `200 OK`, `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`.

### 5. `DELETE /api/books/<book_id>/annotations/<annotation_id>/`
- **Purpose**: Permanently delete an annotation from the ledger.
- **Authentication**: Required (`IsAuthenticated`), Author-only.
- **Status Codes**: `204 No Content`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`.
